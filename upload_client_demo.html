File Manager Client Demo (Upload + Browser)

Satu file HTML untuk meniru konsep end-to-end: multipart upload, progress, folder browser, dan API interaction.

How To Run

Jalankan dari webserver lokal, bukan langsung file://.

  1. Serve file ini dengan webserver statik lokal (pilih salah satu).
  2. Python: python -m http.server 5500
    Node: npx serve . -l 5500
    VS Code: Open with Live Server
  3. Buka: http://127.0.0.1:5500/upload_client_demo.html
  4. Isi Bearer token, pilih file, lalu upload.
